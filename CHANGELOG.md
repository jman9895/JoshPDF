# Changelog

## 1.1.1 — Published baseline

The supplied Windows installer and source identify this version as 1.1.1. Earlier version history was not supplied; this entry records the published baseline rather than inventing changes from previous versions.

- Windows Forms interface for single-file and folder-based qpdf processing.
- Recursive folder mapping, optional known open password, skip/overwrite controls, progress, live results, and graceful stop between files.
- Timestamped failure reports and separate winget dependency installation.
- Inno Setup installer and source launcher.
